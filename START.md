# SINGLE COMMAND STARTUP

## Install concurrently (First Time Only)

```bash
npm install
```

## Run Everything with One Command

```bash
npm run dev
```

This starts:
- Backend on http://localhost:3001
- Frontend on http://localhost:3000

## Open in Browser

```
http://localhost:3000
```

---

**That's it! One command runs everything.** 🚀
